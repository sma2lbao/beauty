# 组件总览

| 组件                                        | 说明                                           | 状态   |
| ------------------------------------------- | ---------------------------------------------- | ------ |
| [Alert 提示条](/components/alert)           | 页面级说明、警告与错误,五种语义类型            | 已发布 |
| [Button 按钮](/components/button)           | 触发一个操作,五种视觉类型、四档尺寸,支持加载态 | 已发布 |
| [Card 卡片](/components/card)               | 内容分块容器,含标题/描述/内容/脚部结构         | 已发布 |
| [Checkbox 多选框](/components/checkbox)     | 勾选/取消两态选择,支持说明文字                 | 已发布 |
| [Empty 空态](/components/empty)             | 无内容时的占位说明,支持操作区                  | 已发布 |
| [Field 字段容器](/components/field)         | label + 控件 + 提示/错误的固定表单结构         | 已发布 |
| [Input 输入框](/components/input)           | 文本录入,支持前后置内容与校验态                | 已发布 |
| [Select 选择器](/components/select)         | 下拉单选,原生 select 的语义化包装              | 已发布 |
| [Skeleton 骨架屏](/components/skeleton)     | 加载前的占位块,脉冲动画                        | 已发布 |
| [Space 间距](/components/space)             | 统一子元素间距与对齐的布局组件                 | 已发布 |
| [Spin 加载指示](/components/spin)           | 旋转圆环,加载进行中的视觉反馈                  | 已发布 |
| [Switch 开关](/components/switch)           | 两个互斥状态之间的即时切换                     | 已发布 |
| [Tabs 页签](/components/tabs)               | 同层内容间切换,支持键盘导航                    | 已发布 |
| [Tag 标签](/components/tag)                 | 标记与分类内容,支持语义色与关闭                | 已发布 |
| [Textarea 多行文本框](/components/textarea) | 多行文本录入,支持校验与禁用态                  | 已发布 |

组件按需扩充:新增组件时遵循现有目录结构(源码、单测、文档、同目录普通 CSS 各一份;类名用 `bd-` 前缀的 BEM 语义类名,样式只在 CSS 里写)。
