# 介绍

Beauty Design 是 beauty monorepo 的 Web 端 React UI 组件库,为内部产品提供统一的界面语言与交互基础。

## 它是什么

- 一个以 **设计令牌** 为核心的样式系统:颜色、圆角、字体以 shadcn 语义 CSS 变量定义,统一使用 `--bd-` 命名空间(`--bd-primary`、`--bd-background` 等),因此不会与宿主主题的同名变量互相覆盖;亮色定义在 `:root`,暗色通过 `.dark` class 显式启用;
- 一组 **行为可预期** 的 React 组件:原生元素语义、受控/非受控双模式、ARIA 属性齐备,`peerDependencies` 仅依赖 React 19;
- 一套 **语义类名 + 普通 CSS 的实现**:每个组件自带一份同目录 CSS,类名是 `bd-` 前缀的 BEM 语义类名(`.bd-button`、`.bd-button--primary`),颜色/圆角/字体只读 `--bd-*` 令牌。组件源码里不出现 Tailwind 工具类,因此宿主不装 Tailwind 也能正确渲染、也不会被库的全局重置影响,并可以用普通 CSS 类名覆写(见[样式与覆写](./styling))。

## 设计原则

**令牌优先。** 任何视觉决策先落在令牌上,再由组件消费令牌。业务方覆盖令牌即可完成品牌定制,不必覆写组件样式。

**克制。** 组件只提供通用能力,不预设业务含义。动效只服务于状态反馈,不做装饰性动画。

**可预期。** 组件不产生请求、不操作路由、不管理业务状态。给它什么 props,它渲染什么,事件原样透传。

## 目录结构

```
packages/design
├── src/                  # 组件库源码
│   ├── components/       # 组件实现
│   │   ├── button/       # Button:按钮
│   │   ├── input/        # Input:输入框
│   │   ├── tag/          # Tag:标签
│   │   ├── switch/       # Switch:开关
│   │   └── space/        # Space:间距布局
│   ├── styles/           # tokens.css(令牌)与 styles/tailwind 两个入口
│   └── lib/              # cn 类名拼接工具
├── docs/                 # Rspress 文档源(本站)
│   └── public/           # 站点静态资源:logo.svg / logo-mono.svg / favicon.svg
├── rspress.config.ts     # 文档站配置
└── vitest.config.mts     # 单元测试配置
```
