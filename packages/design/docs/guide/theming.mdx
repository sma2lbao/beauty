# 主题定制

Beauty Design 的视觉系统由 shadcn 语义 CSS 变量驱动。业务方不需要覆写组件样式,覆盖变量即可。

## 两条引入方式

组件库可以在**不使用 Tailwind 的宿主**里工作,两条路径的令牌完全一致:

| 宿主             | 引入方式                                                                | 说明                                                                                                                                                                                   |
| ---------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 不使用 Tailwind  | `import '@beauty/design/styles.css'`                                    | 样式入口:`--bd-*` 令牌 + 全部组件 CSS,**零 Tailwind**(没有 preflight、没有工具类);链内 `@import` 由宿主打包器内联。宿主可以是纯 CSS、CSS Modules、CSS-in-JS 或任何技术栈               |
| 使用 Tailwind v4 | 在 `@import 'tailwindcss'` 之后 `@import '@beauty/design/tailwind.css'` | 在上一行的内容之外多一层 `@theme` 映射:把 `--bd-*` 暴露成 Tailwind 主题变量,于是你可以直接用 `bg-primary`、`text-muted-foreground`、`rounded-md` 等工具类写业务样式,并自动跟随令牌换肤 |

两种方式下覆盖 `--bd-*` 的写法完全相同。

## 为什么变量带 `bd-` 前缀

令牌统一使用 `--bd-` 命名空间(如 `--bd-primary`)。原因是宿主应用——尤其是同样基于 shadcn/ui 的项目——也会在 `:root` 定义 `--primary`、`--background`、`--radius` 这类全局同名变量;两者优先级相同,后引入的一方会覆盖整个文档,形成双向破坏。

命名空间化之后:

- 宿主令牌不会影响组件库的渲染;
- 组件库也不会污染宿主自己的主题;
- **给 Tailwind 宿主的工具类名仍是标准写法**(`bg-primary`、`rounded-md`、`text-muted-foreground`)。`./tailwind.css` 里的 `@theme inline` 把它们映射到 `--bd-*`,所以使用方无需配置任何 Tailwind 前缀。

> 这里刻意不使用 Tailwind 的 `prefix()`:它会把宿主自己的全部工具类改写成 `bd:bg-primary` 这类形式。令牌隔离已经由 `--bd-*` 命名空间解决,工具类名保持标准才能与宿主既有代码共存。

## 亮色与暗色

变量在 `:root` 上定义亮色主题;在任意祖先节点(通常是 `html` 或 `body`)添加 `dark` class 即切换为暗色:

```tsx
// 跟随用户偏好切换
function syncTheme() {
  const dark = window.matchMedia('(prefers-color-scheme: dark)').matches;
  document.documentElement.classList.toggle('dark', dark);
}
```

组件库不主动监听系统偏好,何时切换、如何持久化,由业务方决定。`.dark` 是 shadcn 的通用约定,宿主自身的暗色切换与本库共用同一次切换。

## 覆盖品牌色

在业务侧的样式里重新定义 `--bd-*` 即可,优先级高于库内默认值:

```css
:root {
  /* 全站替换品牌色与焦点环 */
  --bd-primary: #7c4dbe;
  --bd-ring: #7c4dbe;
}

.dark {
  --bd-primary: #9a6ee8;
}
```

也可以只挂到某个容器上做局部换肤:

```css
.brand-area {
  --bd-primary: #0f766e;
}
```

组件、焦点环、语义色板中的主色引用会一并生效。

## 变量总览

配色走 Vercel / Geist 风格的**单色灰阶**:主色就是"墨"(亮色近黑、暗色近白),
界面靠层次与边框区分而非色相;彩色只保留焦点环与四个小面积语义色。

| 变量                                               | 说明                           | 亮色默认值                        | 暗色默认值                        |
| -------------------------------------------------- | ------------------------------ | --------------------------------- | --------------------------------- |
| `--bd-primary` / `--bd-primary-foreground`         | 主色 / 主色上的文字            | `#171717` / `#ffffff`             | `#ededed` / `#0a0a0a`             |
| `--bd-ring`                                        | 焦点环颜色(Geist 蓝)           | `#0070f3`                         | `#3291ff`                         |
| `--bd-background` / `--bd-foreground`              | 页面背景 / 正文文字            | `#ffffff` / `#171717`             | `#000000` / `#ededed`             |
| `--bd-card` / `--bd-popover`                       | 卡片 / 浮层背景                | `#ffffff`                         | `#0a0a0a`                         |
| `--bd-secondary` / `--bd-muted` / `--bd-accent`    | 次级、弱化、强调底色           | `#fafafa` / `#f5f5f5`             | `#1a1a1a` / `#242424`             |
| `--bd-muted-foreground`                            | 弱化文字                       | `#666666`                         | `#a1a1a1`                         |
| `--bd-destructive` / `--bd-destructive-foreground` | 危险语义色 / 其上的文字        | `#c81e1e` / `#ffffff`             | `#ef4444` / `#0a0a0a`             |
| `--bd-success` / `--bd-warning` / `--bd-info`      | 扩展语义色(Tag 等)             | `#0b7350` / `#955d0a` / `#0060d1` | `#3ecf8e` / `#f5a623` / `#3291ff` |
| `--bd-border` / `--bd-input`                       | 边框 / 输入框边框              | `#eaeaea`                         | `#262626` / `#2e2e2e`             |
| `--bd-radius`                                      | 圆角基准(sm/md/lg/xl 由此派生) | `0.75rem`                         | 同亮色                            |
| `--bd-font-sans`                                   | 正文字体栈                     | 系统字体栈                        | 同亮色                            |

> 品牌月相色(logo 与字标月面)不走 `--bd-*`,由使用方的 `--logo-moon` 单独定义:
> 它是品牌资产而不是主题色,换主题不会牵连它。

“覆盖品牌色”一节里的示例值仍是任意可替换的占位:把 `--bd-primary` 换成任意彩色,
按钮、开关、Tag 主色、焦点环就会整体跟随——这正是从单色切回彩色品牌的做法。
