## 3 剩余缺口清单（按优先级）

### 3.1 P0（正确性 / 钱 / 安全，建议本周内决策）

1. **成本归因缺失**：无价格表/`cost_usd`/货币，`usage_events` 只有 token（`account/models/account.py:75-84`）。**不补的后果**：无法计价、无法按阶段/节点/租户归因成本，商业化定价没有数据基础。
2. **对话直答不计量也不配额**：`services/chat.py` 直接调模型，无 usage/quota（`:203-252`）；用量上报只在 run 边界（`services/run_quota.py:18-34`）。**不补的后果**：免费无限用 + 账单黑洞；与 run 路径的额度语义不一致。
3. **usage 上报 at-most-once**：失败即停只 warning（`services/usage.py:125-139`）。**不补的后果**：模型账单与平台用量长期对不上，且无补偿机制。
4. **多实例正确性（三处）**：outbox `claim` 无锁（`packages/events/events/outbox.py:119-132`）→ 重复投递；jobs 无 lease 续租（`services/jobs_worker.py`，`jobs_lease_seconds=60`）→ 长 run 重复执行；沙箱 reaper 无领取标记（`workspace/services/sandbox.py:525-557`）→ 重复销毁/竞争。**不补的后果**：扩到 2 副本即出现重复事件、重复工具调用、重复计费。
5. **限流仍进程内**：`services/bff/bff/main.py:67-89` 滑窗；Redis 未接。**不补的后果**：副本数一加，实际限额 = N×配置值，等于没有限流。
6. **MCP 注册无 SSRF 校验**：`schemas/mcp.py:45-61` 只校验长度；加载失败静默吞（`graph/nodes.py:122-135`）。**不补的后果**：租户可诱导 orchestrator 访问内网/云元数据；MCP 故障静默降级，用户看到的是「工具没了」而不是错误。

### 3.2 P1（体验 / 可运维性）

1. **checkpoint 列表/回退/fork API**：现 resume 换 thread（`run_execution_approvals.py:208`、`run_execution.py:362`），retry 建 child run（`:280-343`）。**不补的后果**：任何一步失败都要整 run 重跑，长任务成本与等待时间翻倍；07 建议的 rewind 无锚点。
2. **run 级墙钟超时 + 优先级**：无 `run_timeout_seconds`、无 priority 列。**不补的后果**：卡住的 run 永久占并发额度；无按租户/套餐的调度公平。
3. **状态迁移不落事件**：`run_execution.py:144-145` 明说不落事件。**不补的后果**：状态时间线不可回放，无法算「审批等了多久」「执行 vs 等待」SLO；审计只能看终态。
4. **per-run 模型选择 / fallback / 结构化输出**：`RunCreate` 无 model；网关单次调用无 fallback（`services/completions.py:228-243`）。**不补的后果**：单模型故障=全平台不可用；无法按任务选便宜/强模型。
5. **RBAC + 管理面审计**：`api/v1/account.py:41-82` 三个写端点无角色校验、无审计。**不补的后果**：任何成员可改套餐/改他人角色且事后无法追责——企业客户采购的直接阻断项。
6. **通知持久化 + 邮件**：`api/v1/notifications.py:1-5` 明确不建表、不回放。**不补的后果**：关页面就收不到 run 失败/待审批；无邮件通道。
7. **Skills permissions/triggers 不生效**：`grep permissions` 仅 `schemas/skills.py:30`。**不补的后果**：manifest 承诺的权限边界形同虚设；第三方技能包无法做安全审查，市场/分享不可信。
8. **step 级 token 成本 + step↔checkpoint 映射**：`services/run_events.py:164-181` payload 无 tokens/checkpoint_id。**不补的后果**：P0-1 成本归因无维度键；P1-4 回退无锚点（07 §4.3 的依赖顺序）。
9. **知识库检索质量**：默认 local 哈希嵌入（明写非语义，`services/embeddings.py:45-63`）、无 rerank/hybrid（`services/knowledge.py:88-104`）。**不补的后果**：默认部署下检索近乎关键词匹配，RAG 场景不可用。
10. **沙箱 per-tenant 配额 + egress allowlist**：config 无 quota 键；network 仅 deny|public（`workspace/core/config.py:39`）。**不补的后果**：单租户可耗尽沙箱资源；无法「只放行某 API 域名」。
11. **管理面/平台审计导出**：account 零 audit 命中。**不补的后果**：等保/企业审计无法交付。
12. **对象存储 S3**：仅 filesystem/database（`common/artifacts.py:66-81`）。**不补的后果**：多副本部署需共享卷，产物与 DB 耦合。

### 3.3 P2（可延后，但需登记）

1. **hooks / 插件 / SDK / webhook**：全缺（1.2）。后果：外部系统只能轮询 REST；无法在工具调用前后做企业策略拦截。
2. **死配置清理**：7 个键无消费方（§4.2）。后果：运维按文档调参不生效，排障时误判。
