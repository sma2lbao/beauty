## 1. 问题与证据
- 10 份同构 request<T>（account-api:59、api-keys-api:21、conversations-api:90、insights-api:42、knowledge-api:45、mcp-api:112、outbox-api:33、runs-api:90、skills-api:70、workspace-api:47）各自复制 401 续期/错误映射；http.ts:95 requestJson 已存在但仅部分复用（http.ts 被 27 文件引用，含测试）。
- 3 份手写 SSE reader：runs-api.ts:224、conversations-api.ts:318、notifications-api.ts:56，各自 split('\n\n') 手写帧解析；Last-Event-ID/stream.end 语义只在 runs-api 实现，其余无重连抽象。
- 14 处 import.meta.env 散落在 9 个 lib 文件（workspace-api:13、outbox-api:11、site-links:7-8、knowledge-api:15、runs-api:17、account-api:12、conversations-api:14、auth.ts:22-31、notifications-api:9）。
- queryKey 字面量 86 处 queryKey: 出现、58 处直接写数组字面量；失效逻辑靠调用方各自 invalidate（sidebar.tsx:170-171、run-detail.tsx:69-72 等），键名无单一真源。
- presentation.ts 477 行聚合展示工具；formatTime/formatSize 在 7 处重复定义（settings.tsx:33、outbox.tsx:39、knowledge.tsx:27/34、workspace.tsx:39/46、mcp.tsx:95）。
- app.tsx:1-23 静态 import 15 个页面，0 处 lazy/Suspense；构建单 chunk 737954B + CSS 77514B。
- tools/eslint-config/configs/base.js:10-34 只有 ignores，无 import 边界、无 max-lines、无 no-restricted-paths。
- scripts/dev.sh 4 个已知问题（进程组只 kill nx 父进程、lsof 依赖、端口占用误判、首次不 uv sync）；reset-local.sh 不清 services/*/.cache（account 签名密钥在此）。
- docs 门禁缺失：npx prettier --check "docs/**/*.md" 当前 15 文件失败，无 markdownlint/链接检查，gate 脚本未含文档检查。

## 2. 目标与非目标
- 目标：把「请求/流/环境/查询键/展示工具/路由加载」六类复制粘贴收敛为单点基座，为 W2 拆分 chat.tsx（R-17）提供可复用底座；同时建立前端 eslint 边界与文档门禁，防止重构后再次回潮。
- 行为等价定义：所有 API 路径/方法/请求体/响应解析、401 续期一次、SSE 帧语义（meta/delta/tool/done/error、stream.end、Last-Event-ID 重连）、页面路由与守卫顺序、可见文案与时间格式输出全部不变。
- 非目标：不改任何 Python 服务；不动 apps/desktop 主进程；不拆 chat.tsx/页面组件（W2 R-17/R-18）；不做状态管理替换（react-query 保留）；不改 HTTP 契约；不新增运行时依赖（sse 基座手写，不引 eventsource 库）。

## 3. 方案
- R-11：http.ts 增 createHttpClient(base) 工厂，返回 { request, blob, stream? }；10 个 api 文件删除本地 request<T>，改为 const http = createHttpClient(BASE) 后调用；ApiError/401 续期/FormData/204 语义原样。api-keys-api 的 path 默认 '' 保留。
- R-12：新建 lib/sse.ts，导出 readSseStream(response, handlers)（帧切分、event/data 解析、stream.end、注释行 ':' 跳过、decoder flush）与 connectSse(url, {headers,lastEventId,signal,onFrame,onEnd,onOpen,onInterrupted})；runs-api/conversations-api/notifications-api 改为调用；保留各自 onXxx 回调形状与错误 code。
- R-13：presentation.ts 拆为 lib/presentation/{run,events,tools,diff,format}.ts，原文件改为 barrel 再导出（14 个 import 方零改动）；formatTime/formatSize 收敛为 lib/presentation/format.ts 的 formatDateTime/formatBytes，5 个页面删除本地定义改 import（页面内既有时区/相对时间文案保持一致，逐页对照测试）。
- R-10：app.tsx 页面改 React.lazy + 路由级 Suspense（fallback 为骨架组件 components/route-fallback.tsx）；登录/回调/官网页保持同步（体积小、首屏需要），控制台内页全部 lazy；构建后记录 chunk 尺寸。
- R-08：新建 config/env.ts，集中读取并校验 VITE_*（authMode、apiBase：runs/account/knowledge/workspace、logto 三项、siteUrl），导出类型化常量与默认值；9 个 lib 文件改为 import；保持 dev 环境默认同源（''）与生产默认不变。
- R-09：新建 lib/query-keys.ts，键工厂 + 分组失效函数（如 keys.runs.list()、invalidate.conversations(queryClient)）；components/pages 的 58 处字面量替换；保留原有 key 结构（数组形状不变，避免缓存失效行为变化）。
- R-14：base.js 增 import/no-restricted-paths（@/pages 不得从 @/components 反向、lib 不得 import pages/components）、max-lines（warn，阈值高于当前最大文件）、no-restricted-imports（禁止跨层 '@/pages/*' 从 components）；react.js 保持。先 warn，全绿后再评估 error。
- R-16：docs 全部 prettier --write 归零；新增 scripts/check-docs.sh（prettier --check docs + 相对链接存在性 + 锚点存在性 + 禁止「已归档」文档被当前索引误引）；package.json 加 docs:check；refactor-gate.sh 末尾调用；CI 的 setup 之后加 docs-check job（无 Node 依赖，纯 bash+prettier）。
- R-15 顺带（若 w1-tooling 有余量）：dev.sh 用 setsid/进程组 kill、lsof 缺失时回退 ss/lsof 探测、首次启动前 npx nx run <svc>:sync；reset-local.sh 增加 services/*/.cache。若时间不足则保持原样，W1 复盘记为遗留。

## 5. 契约与兼容
- 前端内部 API（http.requestJson/requestBlob/jsonHeaders/ApiError）签名不变；新增 createHttpClient 为增量。
- SSE 语义等价：帧分隔 \n\n、event/data 行、stream.end 判读、注释行忽略、done 后不再回调。
- 页面可见行为不变：路由表顺序、守卫层级（SiteLayout/AuthGuard/ConsoleLayout）、懒加载仅影响加载时机。
- 无 DB/事件/部署契约变化；CI 新增 docs-check job 不阻塞既有 job。

## 6. 验证计划
- 每个 R：npx nx typecheck @beauty/web + npx nx test @beauty/web -- --run + npx nx lint @beauty/web；涉及 lib 的补单测（新增 sse.test.ts、http 工厂测试、query-keys 常量测试）。
- 集成：npx nx build @beauty/web 后核对 chunk（入口 < 737954B）；npx nx run-many -t lint 15/15；python 侧不动，抽样 npx nx test bff（回归无关性）。
- 手工冒烟（本地起 BFF + web）：登录/刷新 401 续期、工作台发消息（SSE 流式）、runs 列表/详情、知识库检索、设置页时间显示、outbox 流。
- 文档：bash scripts/check-docs.sh；npx prettier --check "docs/**/*.md"。

## 8. 风险与回滚
- R-11 风险：10 个 api 文件行为微妙差异（path 默认值、FormData、错误 code），逐文件对照 + 保留既有测试为回归网。
- R-12 风险：SSE 重连/流结束语义变化导致工作台「假死」；runs-api 已有测试覆盖，新增 sse.test.ts 用 ReadableStream 模拟分片。
- R-13 风险：页面时间格式细微差异（时区/相对时间）；逐页保留原实现对照，先抽 format.ts 再替换。
- R-10 风险：懒加载后路由切换闪烁/骨架遮挡；Suspense 放在 ConsoleLayout 内层，登录页不 lazy。
- R-14 风险：新规则对现有 21860 行 web 代码大量告警；先 warn + 阈值，W1 复盘记录命中数。
- 回滚：每步独立 commit，revert 单步即回到上一步全绿状态；无数据迁移，无破坏性契约。
