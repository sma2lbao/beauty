## 4. 偏差与例外

- **D1**（预定）：ci.yml 由 w0-ci 独占，docker-build / check-workspace 接线由 lead 收口统一加——已按此执行（a1f69b6 一次性提交 ci.yml 全部改动）。
- **D2**（预定）：本机 docker CLI 20.10.17 panic、daemon 不可用，镜像构建正确性只能由 CI docker-build 验证；本地证据为 `compose config -q` EXIT 0 + R-36 的 247 项静态清单。
- **D3**：web 镜像 nginx 主进程仍为镜像默认 root（RFC 只要求 Python 服务非 root）；如需全非 root 可换 nginx-unprivileged 并改 listen 8080。
- **D4**：nx release 的 `release.projects` 排除全部 Python 项目——Python 版本由 check-versions.sh 断言 0.1.0 兜底，未接入 Nx 版本管理（跨语言版本编排留后续）。
- **D5**：Python 侧 pip-audit 在本机不可达（pypi 网络），仅 CI 验；npm 侧本地实测 0 漏洞。
- **D6**：metrics 只做「域指标下沉 + 归属注释」，RED 指标基础设施（middleware / observability / tracing）仍用 `common.metrics`，未搬。
- **D7**：`scripts/golden-run/golden_run.py` 808 行属一次性脚本，不计入服务源码 ≤500 阈值。
- **D8**：w0-ci 误跑真实 `npx nx release`（非 dry-run）生成 CHANGELOG.md，经核查只增该文件、无 tag、内容正确，保留为首版基线；后续只用 --dry-run，tag 由 lead 收口时打。
- **D9**：web 仍存 4 个 >400 行源文件（workspace-switcher 543、message-list 528、runs.tsx 448、skills.tsx 432），满足 W2 阈值（≤5）；desktop `src/main/local/agent.ts` 760 行属既有决策「main/preload 运行时不动」，不在本波范围。
