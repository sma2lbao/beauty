## 5. CI 首跑、修复与回填

### 5.1 首跑（run 40153804622，headSha 842a83b，main）

- 结论：**FAILURE**；9 组 31 matrix job 中 29 绿、2 红：
  - `docker-build` → Build web image：`error TS6305: Output file /app/packages/design/dist/index.d.ts has not been built from source file /app/packages/design/src/index.ts`（连带 TS7006）。根因：web.Dockerfile 用 `npm run build --workspace @beauty/web`，而 apps/web/tsconfig.json 的 references 需要 design/console-ui 先 emit dist。
  - `security-audit` → pip-audit exit 1：`the --disable-pip flag can only be used with a hashed requirements files or if the --no-deps flag has been provided`。
- 连带结论：`affected-js` 过去能过只是同批构建竞态——web build 此前没有 `dependsOn: ["^build"]`。

### 5.2 修复（三轮，run 40154585852 → 40155139606 → 40155457226）

- **a25d19a**（web 镜像改 `npx nx build @beauty/web` + `ENV NX_DAEMON=false`；nx.json targetDefaults 增 `build.dependsOn = ["^build"]`；pip-audit 加 `--no-deps`）。
  - 本地等价验证：清空三处 dist 后 `npx nx build @beauty/web --skip-nx-cache` EXIT 0（console-ui → design → web）；`npx nx run-many -t build --skip-nx-cache` 8 项目全绿。
  - 结果：run 40154585852 仍 2 红——docker-build 报 `[UNRESOLVED_IMPORT] Could not resolve '../../vitest.config.mts'`；security-audit 因 `--no-deps` 生效才**真正开始审计 Python 依赖**，暴露 6 个 CVE。
- **bf32a87**（security/audit-allowlist.json 增 3 条 `ecosystem: pip`；新增 `scripts/pip-audit-ignore.cjs` 生成 `--ignore-vuln`；`check-audit-allowlist.cjs` 的 id 正则加 `CVE-`；pypdf 6.21.1→6.21.2、langgraph-checkpoint-postgres 3.1.2→3.2.0、aiohttp 3.14.3→3.14.5、certifi 2026.7.22→2026.10.23；web.Dockerfile 补 `COPY vitest.config.mts`）。
