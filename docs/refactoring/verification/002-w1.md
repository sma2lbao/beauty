## 5. 偏差与处置

1. **R-11 与 R-12 合并为一个提交**：两者在 10 个 api 文件中逐行交织，单独提交会产生「本地 request<T> 已删但 SSE 未迁」的不可编译中间态。已在提交信息与本节记录，复盘见 docs/refactoring/retro/w1.md。
2. **R-15 由「尽力」转正式交付**：4 个缺陷全部修复（含 macOS bash 3.2 不支持的 declare -A）。
3. **R-14 规则从仓库根 eslint 不生效**：根 eslint.config.mjs 仅 base()，webLayerBoundary 在 configs/react.js 组合、由 @beauty/web 的 nx lint（cwd=项目）加载。已在 base.js 注释说明，避免后续误判「规则失效」。
4. **既有环境失败未纳入本波**：workspace-service tests/test_sandboxes.py::test_sandbox_lifecycle 依赖本机 microsandbox rootfs 缓存路径，仍为 W0 遗留（R-15 清理清单已列，非本波引入）。
5. **R-09 半成品接管**：实施者 subagent 中途失败，lead 修复 5 类类型错误（null vs undefined 查询键、logto 命名冲突）后提交；教训写入复盘。
