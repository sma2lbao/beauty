## 4. 偏差与例外

- **D1**（预定）：`services/tool-service/helpers/fs_helper.py`（1058 行）不拆分。它经 `tool_service/services/helpers.py` 的 `helper_argv()` 以 `python3 -c <整份源码>` 注入沙箱，必须是纯 stdlib 单文件脚本——拆成多文件需要改执行契约（沙箱内无同目录兄弟模块可 import）。判定沿用 W3 D8 `golden_run.py` 行为脚本先例，白名单只 WARN。后续可行路径（task-3 建议）：源码分模块 + 构建期拼接打包器，zipapp 在沙箱内不适用。
- **D2**（既有失败，非本波）：`bash scripts/golden-run/golden-run.sh` 在基线提交 4717b3f 上就是 1/9 PASS，阶段 2 断言 `scripts/golden-run/golden_run.py:443` 报 `AssertionError: chat 流没有 delta 增量帧`（`sse_closed frames=2`，伴随 `triage_failed` warning）。在干净主仓库 `/Users/sma2lbao/Code/beauty/beauty`（HEAD 4717b3f）复跑得到完全相同的 1/9 FAIL，故与 W5 改动无关；登记为功能侧待修（P1-F/P1-G 期间 chat delta 契约漂移），不计入本波出口。
- **D3**（既有漂移，未纳入门禁）：`ruff format --check` 在基线提交上已有 9 个文件未格式化（account 7、common 2，ruff 0.16.8）；CI 的 python-lint 只跑 `ruff check`，故长期为绿。W5 未触碰这些文件，建议单独提交一次纯格式化。
- **D4**（既有红门禁，顺带修复）：`npx nx lint llm-gateway` 在 4717b3f 上已红——`tests/test_fallback.py:225` SIM117、`:354` SIM108、`tests/test_multimodal.py:30` F401。CI `python-lint` 的 lintFilePatterns 含 `tests/`，会让该 job 失败，故在 a001359 修掉（断言不变）。
- **D5**（有意不收敛）：agent-orchestrator 保留自建 lifespan（132→139 行），只复用 `create_service_app` + `create_health_router`。原因：`AppContainer` 自己装配 setup_logging/observability/JwtVerifier，且 stop 后再 dispose，套 `build_lifespan` 会重复装配并在错误顺序上 initialize。代码内已注释说明。
- **D6**（service_kit 向后兼容放宽）：为容纳 bff 的限流中间件、workspace 的 provider 收尾、AO 的 CORS 差异，service_kit 新增 `middlewares` 参数、`ReadyCheck` 允许返回 Mapping、`ready_description`、`shutdown_before_verifier`、settings 注解放宽为 `BaseAppSettings`；均为新增可选参数，既有 3 个服务调用面不变（common 测试 146→152，+6 用例覆盖新行为）。
- **D7**（测试侧 patch 目标迁移，语义不变）：拆分把这些 patch 目标换了模块归属——`execution.find_descriptor`→`catalog.find_descriptor`、`SANDBOX_CALL_GRACE_SECONDS`→`execution.limits.*`、`_import_sdk`→`microsandbox._import_sdk`、`_pipe_shell_argv`/pty→`local.*`、`container_module.build_run_graph`（container 因此保持模块而非包）、`subagents._wait_child`（`spawn_subagent` 留在门面）、`memory_service`（`run_execution` 保留模块属性）。全部在切片内同步改测试，用例数不变。
- **D8**（可接受的体量代价）：拆分使总行数 +10844（80435→91279，+13.5%）、文件数 +165（472→637），来自门面重导出、`__init__` 与文件头开销。体量预算按「单文件」设阈值，故不影响出口；后续若收紧总行数需另立指标。
- **D9**（结构约束固化）：`graph/nodes`、`repositories` 拆成包，`core/container.py` 有意保持模块——包化会让 `monkeypatch.setattr(container_module, "build_run_graph")` 静默失效（tests/test_container_context.py:295/301）。后续再动 container 需先迁移测试的 patch 方式。
