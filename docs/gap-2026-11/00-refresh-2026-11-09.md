## 0. 一页结论

1. **主循环已经齐了，缺的是四块地基。** 单 run 闭环（工具 → 审批 → 执行 → 事件 → SSE → UI）、上下文压缩/记忆、技能渐进加载、子代理、模型选择/fallback、沙箱执行（exec/run_code）、Langfuse 观测栈都已落地；剩下的不是「再加一个功能」，而是钱与安全、机制层、工具面长尾、接入形态。
2. **P0 七项里成本归因已落地（2026-11-09，见 [design/cost-attribution.md](../design/cost-attribution.md)），其余六项仍在。** P0-1 之前只有 Langfuse span 里的成本，现在网关算价 → 编排器透传 → `usage_events` 落库 → 用量页出金额，并区分 BYOK/platform、单独统计未计价调用。P0-4 只修了 job claim 1/3；对话直答配额、usage 可靠投递、限流 Redis 化、MCP SSRF、管理面 RBAC 全部仍缺。
3. **P1 的「机制代差」四项全缺**：工具 policy 引擎、hooks、恢复语义（checkpoint/rewind/fork + run 超时/优先级）、MCP 2026-07-28 对齐。这四项是 2026-10 主流 harness 已经抬高的门槛，不是可选项。
4. **工具面只差长尾**：`web_search`、后台任务 `job_start/job_output/job_kill`、跨实例持久 shell 全仓仍为零；eval harness 与平台成本看板也缺（观测三角只差质量门禁）。
5. **前端/桌面端不缺页面，缺原地闭环**：计划编辑仍断在 `/runs`、失败无重试/消息编辑重发、无复制/重生成、无错误边界、用量页没有钱、桌面端 md/diff/审批与 `shell.run` 无 UI。
6. **排期建议**：批次 1（钱与安全，1–2 周）→ 批次 2（机制层，2–4 周）→ 批次 3（工具面/体验/接入）→ P2 生态在「有外部用户」之后再启动。

### 4.2 逐项现状与做法

- **P0-1 成本归因 ✅**：已按「网关单源计价 → 编排器透传 → `usage_events` 落库 → `/usage/summary` 聚合 → 用量页出金额」落地，详见 [design/cost-attribution.md](../design/cost-attribution.md)。要点：价目表复用 litellm 本地表（含缓存价）不新造 `pricing.py`；`usage_events` 加 `cost_usd`（NULL=未计价）与 `billing_source`（platform/byok）；未计价调用单独计数而不是按 0 元吞掉。**残余**：`step_id/phase` 维度拆分、BYOK 调用审计、金额随 usage 的可靠投递（属 P0-3）。
- **P0-2 对话直答配额**：流式直答已上报（`run_id=None`），但 `chat.answer` 非流式不记；配额只在 run 准入（`run_lifecycle.py:91` → `run_quota.py:63-91`），chat 路径完全绕过。做法：chat 前 `_enforce_quota`，非流式补记，composer 余额提示。**直答是主流量，现在等于白用。**
- **P0-3 usage 可靠投递**：`UsageReporter.report` 逐条 POST，任一条失败就 `return`，只加指标与 warning；接收端无幂等。做法：复用 `events.outbox`（至少一次 + event_id + 消费去重），account 侧补幂等键。**丢一条就少计一次费，且 P0-2 的配额依赖准确用量。**
- **P0-4 多实例**：job claim 已 `SKIP LOCKED`；outbox claim 无锁、无 `claimed_until`；job lease 60s 不续租（长任务会被重复领）；sandbox reaper 无领取标记（多副本重复回收）。做法：outbox claim 改 `FOR UPDATE SKIP LOCKED` + 租约；worker 心跳续租；reaper 加原子领取；补多副本测试。
- **P0-5 限流 Redis 化**：进程内 `deque`，多副本下限流形同虚设；无 redis 依赖/配置，compose 注释自认未接。做法：接 `REDIS_URL`，`rate_limit` 改 Lua/INCR 实现，缺 Redis 时启动告警而不是静默降级。
- **P0-6 MCP SSRF**：只校验 `http(s)://` 前缀，服务端直连用户填的 URL；同仓 `fetch/file_capture` 有私网防护而 MCP 没有；自动加载失败静默吞异常，只在手动 test 时落 `last_error`。做法：私网/元数据地址拒绝 + `ALLOWED_HOSTS` + 加载失败事件/指标 + UI 展示。
- **P0-7 管理面 RBAC/审计**：拆租户后只剩 `/me` 与 sessions，User 无 `role`，全仓无 `/admin`、无 audit 表。做法：先定义管理面（谁看什么），再落 role + 审计中间件；不定义就做，等于给空壳加锁。
